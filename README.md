# David Pinto Ramos

[dpintoramos.github.io](https://dpintoramos.github.io/)

My research website, with interactive simulations and code from my work on nonlinear dynamics, pattern formation and ecological systems.

## Local preview

```sh
python3 -m http.server 8000 --bind 127.0.0.1
```

Open [localhost:8000](http://127.0.0.1:8000/).

## Simulations

The interactive models use [VisualPDE](https://visualpde.com/), by Benjamin Walker, Adam Townsend and Andrew Krause. Equations, parameters and source notes are in [`lab/`](lab/). See the [software licences](lab/visualpde/LICENSE.md).
